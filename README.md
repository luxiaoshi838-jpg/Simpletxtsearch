# 简搜（Simpletxtsearch）

“简搜”是一个独立的安卓 TXT 文件夹全文检索工具。

## 首版功能

- 通过安卓系统文件夹选择器授权一个总文件夹
- 自动列出总文件夹下的一级子文件夹
- 子文件夹默认全选，可取消勾选以排除整个子目录树
- 根目录中的 TXT 始终参与搜索
- 递归搜索已勾选子文件夹中的所有 `.txt`
- 每个文件第一次发现目标文字后立即停止读取该文件，并搜索下一个文件
- 结果只显示文件名，不显示正文或匹配片段
- 使用前台服务后台运行，切换应用或锁屏后仍可继续
- 通知栏显示扫描数量和命中数量，可停止任务
- 支持 UTF-8、UTF-16、GB18030/GBK/GB2312 及自动编码识别
- 可选择是否区分大小写
- 可复制全部命中文件名
- 记住最近使用的总文件夹和子文件夹选择

## 搜索范围规则

选择总文件夹后，软件只让用户勾选它的**一级子文件夹**。取消某个一级子文件夹后，该文件夹和其全部下级文件夹都不会被扫描。总文件夹根目录中的 TXT 默认保留在搜索范围内。

## 后台运行

搜索由用户点击“开始后台搜索”后启动 Android 前台服务。状态栏会显示持续通知。系统“强行停止”应用后任务会结束，这是 Android 的系统限制。

## 构建

要求：JDK 17、Android SDK 35、Gradle 8.2.1。

```bash
gradle testDebugUnitTest
gradle assembleDebug
gradle assembleRelease
```

GitHub Actions 会在每次推送时执行单元测试并生成 Debug/Release APK；每个 Gradle 阶段均有 5 分钟硬超时。
